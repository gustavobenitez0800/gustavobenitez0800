## Lo que construí

### [Veltronik](https://github.com/gustavobenitez0800/Gimnasios-Veltronik) · [veltronik.com.ar](https://veltronik.com.ar)

Sistema de gestión para gimnasios, en producción. Lo diseñé, lo desarrollé y lo opero.

- SaaS multi-tenant: Java 17 + Spring Boot, React, Electron y PostgreSQL.
- Control de acceso con molinete de reconocimiento facial y check-in por QR.
- El mostrador sigue funcionando sin internet y se sincroniza solo al volver la conexión.
- Cobro mensual de la suscripción con Mercado Pago.
- Tests automáticos, migraciones de base versionadas y despliegue continuo a Google Cloud.
